# Saved wardrobe reviews

Save `luna-wardrobe-fit.json` and `luna-wardrobe-preview.png` here after adjusting
items in the interactive studio. Tell the developer when they are ready to apply.
The version 2 JSON includes every item's independent fit, replacement PNGs (if
loaded), the selected outfit, and the reviewed animation pose. The preview PNG is
the whole character, not an accessory sprite. Saving does not alter the game.

Earlier bowler-only reviews remain in `../bowler-review/`; the studio still imports
those JSON files. Preserve review pairs when applying their settings to live assets.
