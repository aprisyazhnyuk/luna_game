# Privacy · Luna prototype

Updated 26 September 2026.

The game has no accounts, advertising, analytics, trackers, or third-party embedded content. It does not request your photos, contacts, location, camera, or microphone.

Your best distance is stored in your browser's local storage under `luna.best.v1`. Game files are stored in your browser's cache for offline play. The game does not upload your score. Clear this site's data in browser settings to remove both; that also removes offline availability until you visit online again. Saves do not automatically transfer between devices.

When you load the hosted game online, the hosting provider receives ordinary web requests needed to serve the files. If deployed on GitHub Pages, GitHub's own privacy statement applies to that hosting: https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement.

Reference photos supplied during development are not bundled with this game. This notice describes the current prototype and should be updated if features or data handling change.
